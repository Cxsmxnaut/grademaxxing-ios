Additional passing native checks cover the normalized attendance fixture from the actual backend adapter, date/leap-year/month boundaries, calendar filtering, all four school resource routes, per-record caching and stale-response invalidation, immediate local session deletion during a slow read, and rejection of a late login after sign-out. This check found and verified a fix for the Quick Look delegate's Swift 6 isolation. It does not establish an iPhone build or runtime behavior.

The native editor and Apple Charts view compile in macOS debug/release and pass Catalyst type checking. Their iPhone interactions remain unverified.

## Unverified gates

- **iPhone UI tests:** Seven synthetic XCTest cases are saved and registered in the shared scheme. `swiftc -frontend -parse UITests/GrademaxxingUITests.swift` passed syntax validation. The cases have not been type-checked, built, or executed with the iOS XCTest framework.
- **iOS build and simulator:** Full Xcode, the iOS SDK, `xcodebuild`, and `simctl` are not installed. The selected developer directory is `/Library/Developer/CommandLineTools`. An iOS build has not been run.
- **Native visual QA:** A macOS demo app was launched from the compiled sources, but Computer Use reported the Mac is locked. No native screen or interaction was visually verified. The macOS compile is not an iPhone validation result.
- **Quick Look and file protection:** The iPhone Quick Look branch passes Mac Catalyst type checking and iOS-target syntax parsing. Actual iPhone preview rendering, device file protection, and app-switcher behavior remain unverified. Passive formats are supported; active/unsupported formats and image-only message content use an explicit portal fallback.
- **Keychain runtime and lifecycle UI:** The Security-framework vault compiles. The automated session tests use an in-memory vault and synthetic transport; they do not establish on-device Keychain, backgrounding, navigation, or accessibility behavior.
- **Live school integration:** No designated account was provided or authorized. No live sign-in, portal read, student record capture, or real credential operation was performed.
- **Distribution:** Signing team, final icon, full privacy disclosures, native CI, feature parity, and TestFlight/App Store review remain on the roadmap. The privacy manifest is a scaffold and must be reconciled before distribution.

The first failure of `swift test` established that Command Line Tools lacks Apple's Testing module. The final check suite uses `swift run GrademaxxingChecks` and has no dependency on XCTest, Swift Testing, or external packages.
